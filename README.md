# 🐾 Atividade 03 · 1º ano · Landing Page EducaCão (HTML5 e CSS3)

> 📅 **Prazo de entrega: de 30/11 a 04/12.** Trabalhos entregues depois de 04/12 não serão aceitos.

Você é o(a) desenvolvedor(a) contratado(a) pela **EducaCão**: monte a landing page **igual ao `modelo.pdf`**, preenchendo os textos do `index.html` e as alternativas do `css/style.css`.

## 📘 Siga o PDF da pasta `explicacao/`

**A explicação passo a passo está no PDF** **`explicacao/1_HTML_e_CSS.pdf`**: cada regra do `style.css`, na ordem do código, com o que cada linha faz e desenhos mostrando o resultado.

> Ele mostra as respostas, mas o objetivo é **entender**: tente primeiro, use o PDF quando travar e confira o porquê de cada valor.

## 🚀 Para começar

1. Clique no botão verde **Code** → **Download ZIP**.
2. Extraia o ZIP (botão direito → **Extrair tudo**).
3. No **VS Code**: **File → Open Folder** e escolha a pasta extraída (a que tem `index.html`, `css`, `img` e `modelo.pdf`).
4. Instale a extensão **Live Server**, abra o `index.html` e clique com o botão direito em **Open with Live Server**. Deixe o navegador ao lado do VS Code: a cada **Ctrl + S** a página muda.

**Como completar:**
- **`index.html`:** troque cada `___` pelo texto do `modelo.pdf` (inclusive os `alt` das imagens).
- **`css/style.css`:** de cima para baixo, leia as opções **A, B e C** de cada propriedade e digite o **valor** (ex.: `display: flex;`, não `display: B;`). Comece pelo `:root`.
- **`css/base.css`:** **não mexer**.

## 🎨 Personalização (opcional, depois de ficar igual ao modelo)

Você pode trocar **cores** (no `:root`), **imagens** e **textos**. **Não mude a estrutura**: tags, classes, IDs, a ordem das seções, os blocos `@media`. O resultado tem que continuar parecido com o `modelo.pdf`.
